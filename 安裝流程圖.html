項目來源大小時機
Python 執行環境 nuget.org ~30 MB 僅首次
Python 套件(GPU 模式,含 PyTorch) pypi.org + download.pytorch.org ~5 GB 僅首次 / 模式切換時
Python 套件(CPU 模式,不含 PyTorch) pypi.org ~1 GB 僅首次 / 模式切換時
ffmpeg / ffprobe github.com/BtbN/FFmpeg-Builds ~160 MB 僅首次
Breeze-ASR-25 語音模型 huggingface.co ~3 GB 首次「開始」轉錄時
YouTube 影音本體 youtube.com(經 yt-dlp) 依影片而定 每次下載新影片
